PandaScore Tracker WordPress Plugin
===================================

Installation Instructions:
1. Upload via WordPress Admin > Plugins > Add New > Upload Plugin
2. Or extract to your /wp-content/plugins/pandascore-tracker/ directory
3. Activate the plugin through the 'Plugins' menu in WordPress
4. Go to Settings > PandaScore Tracker to configure your API key
5. Use the shortcode [pandascore_tracker] in your posts or pages

Shortcode Usage:
[pandascore_tracker game="valorant" limit="5" title="UPCOMING MATCHES"]

Parameters:
- game: Game type (default: "valorant")
- limit: Number of matches to display (default: 5)
- title: Header title (default: "UP-COMING")
